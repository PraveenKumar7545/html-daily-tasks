# 🍛 Covai Anganan Biriyani Website

A simple restaurant website developed using **HTML5**. The project showcases the restaurant's menu, traditional biriyani, food videos, and contact navigation through a clean multi-section webpage.

## 🚀 Features

- Responsive Navigation Bar
- Hero Banner
- Biriyani Special Section
- Traditional Food Section
- Restaurant Menu Video
- Food Videos Gallery
- Footer with Navigation Links

## 🛠️ Technologies Used

- HTML5
