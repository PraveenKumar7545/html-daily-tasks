# HTML Daily Task 05 - Credit Card Payment Form

## 📌 Description

Created a Credit Card Payment Form using HTML5.

This webpage allows users to select a credit card type, enter and re-enter their credit card details, provide email and mobile number, enter a payment amount, select a bank account, and submit the payment form.

## 🛠️ Technologies Used

- HTML5

## 📚 HTML Concepts Covered

- HTML Forms
- Radio Buttons
- Images
- Number Input
- Email Input
- Select Dropdown
- Option Elements
- Placeholder Attribute
- Labels
- Submit Button

## ✨ Features

- Credit card type selection
- Visa, Mastercard, and RuPay card options
- Credit card number input
- Credit card number confirmation
- Email ID input
- Mobile number input
- Payment amount input
- Bank account selection
- Submit button
