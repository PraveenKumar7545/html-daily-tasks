# HTML Daily Task 06 - NAB Personal Banking Webpage

## 📌 Description

Created a complete personal banking webpage using HTML5.

This webpage represents a banking website with navigation links, banking solutions, home loan information, savings information, online safety content, and footer sections.

This is the final task in my HTML daily practice series.

## 🛠️ Technologies Used

- HTML5

## 📚 HTML Concepts Covered

- HTML Document Structure
- Semantic HTML
- `<header>`
- `<nav>`
- `<main>`
- `<section>`
- `<article>`
- `<footer>`
- Headings and Paragraphs
- Links
- Images
- Ordered and Unordered Lists
- `alt` Attribute
- HTML Comments
- HTML Entities
